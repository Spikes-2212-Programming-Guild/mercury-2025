# Mercury 2025 FRC Scouting App

## Overview

Mercury 2025 is a scouting application designed to help FRC teams collect and analyze match data.

## Features

- **Mobile**: Designed for mobile devices
- **Offline Capability**: Stores data in local storage to work without constant internet connection
- **Configurable**: Form structure defined in JSON for easy customization
- **Cross-Platform**: Web-based application that can be packaged for Android using Capacitor
- **Optimized**: Built in raw JavaScript, HTML, and CSS for max performance

## Development

To run the application locally, run the file newSever.js by running `node newServer.js` in the root directory.

## Configuration

The form structure is defined in `docs/config/form.json`
